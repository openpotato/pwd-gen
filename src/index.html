Standards & references

  • Password authentication guidance: NIST SP 800-63B-4 provides current guidance and requirements for passwords used as authentication secrets, including password length, permitted characters, blocklists and verifier behavior — NIST SP 800-63B-4.
  • Password generation and randomness: RFC 4086 / BCP 106 describes security requirements for random values and includes password generation as a specific use case — RFC 4086.
  • Cryptographic random values in browsers: This generator uses crypto.getRandomValues(); the W3C Web Cryptography API specifies it as a source of cryptographically strong random values — Web Cryptography API.
